# Renzo Romero

Hello there, this file will assist you in getting this program running locally on your machine and using both the chooseADog and dogFact Pages

## Instructions


1.On GitHub, navigate to the main page of the repository.


2.You will see a green button that says code, click on it

![](https://i.sstatic.net/V4WR6.png)

3.Copy the URL(HTTPS,SSH or GitHub CLI) for the repository.


4.Open Git Bash(you can download it [here](https://git-scm.com/install/windows)) .


5.Change the current working directory to the location where you want the cloned 
directory.

```
cd YOURFILEDIRECTORY
```


6.Type git clone and paste the repository https://github.com/YOUR-USERNAME/YOUR-REPOSITORY

```
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
```


7.Press Enter to create your local clone.

If you're having trouble following these instructions or ran into issues then check out [gitHub documentation](https://docs.github.com/en/get-started/start-your-journey/downloading-files-from-github) for more info on a specific topic/issue

To use the dogFacts or Choose a dog,simply click an option from the dropdown menu
to reveal information .To navigate between pages use the left or right navigation link.
