Hello there, If your interested in downloading this repository and getting it running on your local machine:
1.On GitHub, navigate to the main page of the repository.
2.You will see a green button that says clone, click on it
3.Copy the URL(HTTPS,SSH or GitHub CLI) for the repository.
4.Open Git Bash(you can download it here: https://git-scm.com/install/windows).
5.Change the current working directory to the location where you want the cloned directory.
6.Type git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY
7.Press Enter to create your local clone.

If you're having trouble following these instructions or ran into issues then check out gitHub documentation for more info on a specific topic/issue( https://docs.github.com/en/get-started/start-your-journey/downloading-files-from-github)
